# UC005 — Enviar alerta aos gestores técnicos

## Objetivo

Enviar alerta aos gestores técnicos e conferir o resultado previsto nos critérios relacionados.

## Requisitos relacionados

RF03012 — Envio de alertas de manutenção preventiva.

Critérios do OpenProject — #25229

## Ator

Sistema e gestores técnicos.

## Preparação e dados

Alerta A01 elegível para envio. Usuários G01 e G02 possuem perfil Gestor Técnico. U01 possui outro perfil.

Cada alternativa parte de uma preparação independente. Os dados são fictícios.

## 🟢 [FP] — Fluxo principal

O sistema identifica os usuários com perfil Gestor Técnico. Encaminha A01 a G01 e G02. Confere os destinatários do alerta para verificar a inclusão dos gestores e a ausência de U01.

## 🟠 Fluxos alternativos

A1 — Apenas U01 disponível. U01 não recebe o alerta por esse fluxo. A destinação do alerta sem gestores depende de D06.

A2 — Solicitante do serviço possui outro perfil. Aplicar a restrição de destinatários do #25229. A diferença encontrada no código está registrada em D06.

## 🟣 [RN1] — Regras de negócio

O envio é exclusivo para perfil Gestor Técnico pelo #25229. A US #25236 explicita todos os usuários desse perfil.

## Resultados esperados

G01 e G02 recebem A01. U01 não é destinatário.
